# Convenciones de MARRSO

- Usar siempre Lucide para los iconos de interfaz, mediante el paquete oficial `@lucide/angular`.
- Importar únicamente los iconos utilizados en cada componente; no cargar el catálogo completo.
- No introducir emojis, caracteres Unicode, dibujos CSS ni SVG manuales como sustitutos de iconos de interfaz.
- Mantener los iconos decorativos ocultos a lectores de pantalla; el control debe tener un texto o nombre accesible.
- El logotipo de MARRSO y las ilustraciones propias de producto son recursos de identidad, no iconos de interfaz.
